
# Milestone 1: Swift Foundations

## Objective
Demonstrate understanding of Swift fundamentals,
generics, memory management, and error handling.

## R1: Gradebook
- Implemented using Dictionary and Arrays.
- Calculated student average marks.
- Used safe optional handling.
- Used guard, if let, and nil coalescing.

## R2: Generic Stack
- Created a generic Stack<T> structure.
- Implemented push(), pop(), and peek().
- Demonstrated with Int and String types.

## R3: Retain Cycle
- Demonstrated object relationships.
- Used weak references to prevent retain cycles.
- Explained Automatic Reference Counting (ARC).
- Verified object deallocation using deinit.

## R4: Error Handling
- Created custom ValidationError enum.
- Implemented a throwing validation function.
- Handled empty name and invalid age errors.
- Used do-catch for error handling.

## R5: Viva Topics
- Struct vs Class
- Protocol vs Inheritance
- map(), filter(), and reduce()

## Technologies
- Swift
- Visual Studio Code
- Swift Compiler

## Execution
Run each file independently:

swift R1_Gradebook.swift
swift R2_GenericStack.swift
swift R3_RetainCycle.swift
swift R4_Validation.swift
