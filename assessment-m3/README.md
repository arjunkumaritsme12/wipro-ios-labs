
# Milestone 3 - UIKit Assessment

## Objective
Build a UIKit application demonstrating forms,
network requests, JSON decoding and navigation.

## Requirements

### R1 - UIKit Form
- Registration form
- Name validation
- Email validation
- Password validation
- Auto Layout constraints

### R2 - JSON and Codable
- Fetch posts using URLSession
- Decode JSON using JSONDecoder
- Display posts using UITableView

### R3 - Application States
- Loading indicator
- Empty state
- Failure state
- Retry functionality

### R4 - Navigation
- Registration screen to Posts screen
- Posts screen to Detail screen
- UINavigationController

### R5 - Viva Topics
- UIKit View Hierarchy
- Auto Layout
- URLSession
- Codable
- UITableView
- UINavigationController

## API Endpoint

https://jsonplaceholder.typicode.com/posts?_limit=20

## Technologies

- Swift
- UIKit
- Foundation
- URLSession
- Codable
- Auto Layout
- UITableView

## Important

The registration form performs local validation.
It does not create a real user account.

UIKit application compilation and simulator testing
require Xcode on macOS.
