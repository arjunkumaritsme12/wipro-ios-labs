
# Lab 8D: SwiftUI Layout and Form Interaction

## Objective
Build a responsive event registration form with declarative validation.

## Requirements Completed
- R1: Text fields, picker, toggle and submit button.
- R2: Form, Section, spacing, padding and alignment.
- R3: Validation feedback and success confirmation.
- R4: Disabled submit button for invalid input.
- R5: Tested empty input, long text and small-screen layout.
