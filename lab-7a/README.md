# Lab 7A - UIKit Profile Form

## Objective
Build a responsive UIKit profile form using UIView
and UIViewController.

## Features

- Full Name input field
- Email Address input field
- Course input field
- Submit Profile button
- Auto Layout constraints
- Required field validation
- Email format validation
- Inline validation error
- Alert-based feedback
- Keyboard dismissal
- Accessibility labels
- Dynamic Type support
- Dark Mode support
- ScrollView for smaller screens

## Technologies

- Swift
- UIKit
- Auto Layout
- UITextField
- UIStackView
- UIAlertController

## Validation

1. Submit empty form.
2. Enter only name.
3. Enter invalid email.
4. Leave course empty.
5. Enter all valid details.
6. Enter email without domain extension.

## Simulator Testing

Test on two different iPhone simulator sizes
in portrait orientation.

## Expected Result

The form should adapt to different screen sizes
without using fixed screen coordinates.
