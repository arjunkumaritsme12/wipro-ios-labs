# Lab 7C - UI Controls and View Lifecycle

## Objective
Build an interactive UIKit application demonstrating
UI controls, state changes and view lifecycle methods.

## UI Controls

1. UITextField - Name input
2. UIButton - Update Summary
3. UISwitch - Notifications
4. UISegmentedControl - Course selection
5. UISlider - Experience level
6. UIDatePicker - Date selection

## Features

- Interactive UI controls
- UserPreferences model
- Dynamic summary panel
- UIKit lifecycle logging
- Two-screen navigation
- Keyboard handling
- ScrollView-based responsive layout
- Accessibility labels
- Dynamic Type
- Dark Mode support

## Lifecycle Methods

- viewDidLoad()
- viewWillAppear()
- viewDidAppear()
- viewWillDisappear()
- viewDidDisappear()

## Testing

1. Enter a name.
