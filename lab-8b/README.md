
# Lab 8B: Navigation and Basic Template

## Objective
Understand the SwiftUI application entry point and implement predictable navigation.

## Requirements Completed

- R1: Inspected the @main App entry point and WindowGroup.
- R2: Implemented NavigationStack and NavigationLink.
- R3: Passed the selected Course model to CourseDetailView.
- R4: Added toolbar actions and automatic back navigation.
- R5: Explained the difference between App and View.

## Additional Feature
Implemented a SearchView with searchable course results.

## Technologies
- Swift
- SwiftUI
- NavigationStack
- NavigationLink
- State management

## Project Structure
- App: Application entry point
- Models: Course data model
- Data: Sample course information
- Views: Home, detail and search screens

## How to Run
1. Open the project in Xcode.
2. Ensure all Swift files belong to the app target.
3. Set the deployment target to iOS 16 or later.
4. Build and run using an iOS Simulator.
